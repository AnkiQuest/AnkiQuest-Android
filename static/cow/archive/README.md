# Archived Android exports

These generated Bluma exports keep their exact bytes under the
[repository licence](../../../COPYING). OpenAI image_gen generated the
masters without exposing its model identifier; the repository's Rust
exporter produced these WebPs.

The app uses the identical `bluma_asleep.webp` and `bluma_happy.webp`
resources. This archive is outside packaged resources and assets.
