These and aki_sad.webp, aki_hopeful.webp, aki_frozen.webp and
aki_neglected.webp were generated with OpenAI's built-in image_gen tool.
The tool did not expose its model identifier. Their masters, prompts
and cleanup record live in AnkiQuest/AnkiQuest-Desktop, under
docs/branding/core-poses-2026-11/. Exports use that repository's Rust tool.

Linux exports are canonical until the exporter is platform-independent.

The Ankilope additions (ankilope_sad.webp, ankilope_hopeful.webp,
ankilope_frozen.webp, ankilope_sleeping.webp and ankilope_neglected.webp)
come from generated masters in AnkiQuest/AnkiQuest-Desktop commit
0f12507ef07956937a90416a0f1832eba63a634a, using the same tool and documented
alpha cleanup. All five files match the canonical Linux export byte for
byte, verified on 2026-11-15 in PR #323:
