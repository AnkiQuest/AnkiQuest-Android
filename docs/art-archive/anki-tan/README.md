# Archived Android exports

Anki-tan by Shigeyuki (https://www.patreon.com/Shigeyuki).

The generated derivative `anki_tan_sleeping.webp` retains its exact bytes
and CC BY-SA 4.0 licence; see [LICENSE](LICENSE). It was generated with
OpenAI image_gen, which did not expose its model identifier, then exported
from the master by the repository's Rust tool.

The app uses the identical `anki_tan_asleep.webp` resource. This archive is
outside packaged resources and assets.

SHA-256: `3c9876172542efa032c932e583f64fc1bcee2e5c70abad5e8f565e167c0b6f4c`.
Original path: `AnkiDroid/src/main/res/drawable-nodpi/anki_tan_sleeping.webp`.

[Aldana approved archiving this file](https://github.com/AnkiQuest/AnkiQuest-Desktop/issues/88#issuecomment-6918911105).

`anki_tan_neglected-three-blue-stars.webp` preserves the previous neglected
export with all three headband stars blue. Its original path was
`AnkiDroid/src/main/res/drawable-nodpi/anki_tan_neglected.webp`; SHA-256 is
`4f66fc71f4cf373f911f95151a73bd00b4d84669543444b5bef9b285924a5bfc`.
Aldana approved the revised image with one unlit star in
[this decision](https://github.com/AnkiQuest/AnkiQuest-Desktop/issues/88#issuecomment-6921793082).
Both versions retain the credit and CC BY-SA 4.0 licence above.
